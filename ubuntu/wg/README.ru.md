# wg-network

[English version](README.md)

**wg-network** строит и обслуживает WireGuard-сети на production-серверах Linux: hub с публичным адресом и любое число peer (серверы, шлюзы офисов, ноутбуки, телефоны). Утилита закрывает весь жизненный цикл сети: установка одной командой, подключение сервера по SSH одной командой, маршрутизация между peer, site-to-site, exit node, IPv6, резервные копии и восстановление.

Главное правило: **работающий VPN и SSH-доступ важнее любого изменения.**

- Подготовка изменения и его применение — разные шаги; перед каждым изменением показывается план.
- Изменения peer применяются горячо: остальные туннели не прерываются.
- Изменения, которые могут оборвать связь, выполняются под таймером автоматического отката, как `netplan try`. Таймер переживает обрыв SSH и перезагрузку.
- Изменения, которые оборвали бы SSH-сессию, блокируются, пока ты явно их не разрешишь.
- Каждое изменение начинается со снимка: прерванная команда откатывается, а любое прежнее состояние можно вернуть.
- `--dry-run` действительно ничего не меняет: это проверяется тестами для каждой команды.

```bash
curl -fsSL https://raw.githubusercontent.com/Ange1oc/devops_template/main/ubuntu/wg/install.sh | sudo bash

sudo wg-network init hub --endpoint vpn.example.com                 # на hub
sudo wg-network deploy worker1 root@203.0.113.21 --install          # подключить сервер, с hub
sudo wg-network peer add phone --generate --qr                      # телефон или ноутбук
sudo wg-network status
```

## Коротко

| | |
|---|---|
| Платформы | Ubuntu 20.04+, Debian 11+ (проверено на Ubuntu 22.04, 24.04, 26.04), bash 4.4+, модуль ядра WireGuard, рекомендуется systemd |
| Топология | звезда (hub and spoke); peer по умолчанию изолированы; по выбору — маршрутизация, NAT, site-to-site, full tunnel, dual-stack IPv6 |
| Куда ставится | `/opt/wg-network`, команда `/usr/local/bin/wg-network` |
| Генерируемый конфиг | `/etc/wireguard/<iface>.conf`, стандартный `wg-quick`, работает без wg-network |
| Состояние | `/etc/wireguard/wg-network/<iface>/` |
| Зависимости | `wireguard-tools`, `iproute2`; `iptables` для маршрутизации и NAT; больше ничего |
| Язык интерфейса | сообщения на русском; команды, опции, JSON и коды выхода от языка не зависят |

## Насколько проверено

Проект проверяется на нескольких уровнях без моков сетевой части: unit-тесты, сквозные тесты с модулем ядра WireGuard в network namespace (17 узлов, настоящие handshake, NAT, site-to-site, сбои, откаты), интеграционные тесты с настоящими systemd и OpenSSH в контейнерах и те же наборы на нескольких версиях Ubuntu. Покрытие измеряется по трассировкам выполнения. См. [Разработка](docs/ru/development.md#тесты).

Не проверено: виртуальные машины и железо, Debian/RHEL, внезапное отключение питания, успешная загрузка из GitHub внутри тестов. См. [Ограничения](docs/ru/operations.md#ограничения).
